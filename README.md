# WCC Report Studio

Aplikasi web statis (HTML + CSS + JavaScript, tanpa build) untuk membuat laporan mingguan & bulanan.

- `index.html` – struktur halaman
- `style.css` – tampilan
- `app.js` – logika aplikasi

Jalankan lokal: buka `index.html` (atau pakai ekstensi *Live Server* di VS Code).
Deploy: hubungkan repo ini ke Vercel (Framework Preset: **Other**, tanpa build command).

Catatan: data tersimpan di localStorage browser masing-masing. Gunakan menu **Backup data** di langkah 1 secara berkala.
